## Timer One Library
This file contains the library for Timer 1 on the Teensy 4.1
- It can install it by extracting the folder into the libraires folder of the arduino IDE
- It can also be installed by zipping the folder and using the add Zip library option in the arduino IDE
- Example programs are provided 
- function information can be found at https://www.pjrc.com/teensy/td_libs_TimerOne.html
